# Редизайн LifeHub

## Сравнение с прежним интерфейсом

В макете были упрощены или отсутствовали перечисленные ниже возможности. При переносе в приложение они сохранены.

| Возможность | Новая реализация |
| --- | --- |
| Описания, ссылки и повторение задач | Сохранены. Длинные описания раскрываются, повторение настраивается в прежней форме. |
| Обычный, компактный и календарный вид задач | Сохранены. Один фильтр списка и компактный переключатель видов. |
| Перетаскивание и порядок задач | Сохранены, включая изменение даты при перестановке задач недели. |
| Просроченные задачи, неделя, задачи без срока | Сохранены. Группа «Позже» включает и отдалённые сроки. |
| История выполненных задач | Сохранена с дозагрузкой. Календарь запрашивает историю выбранного дня с учётом пагинации. |
| Привычки по дням недели, недельные цели, пропуски, серии и история | Прежние формы, расчёты и элементы истории сохранены. |
| Цели и связанные задачи, привычки, зависимости и записи | Сохранены. Выполненные цели отображаются карточками; добавлен возврат в работу. |
| Markdown, ссылки, закрепление, копирование, редактирование и удаление записей | Сохранены. Короткие записи не получают кнопку раскрытия; действия находятся в меню. |
| Поиск и фильтры дневника по сфере, цели и зависимости | Сохранены. Поиск виден сразу. |
| AI-рефлексия и пометка AI-записей | Сохранены. |
| Календарь зависимостей, срывы, тяга, рекомендации, статистика и история | Прежние компоненты и действия сохранены. |
| NSFW-настройка и скрытие связанных записей | Сохранены, в том числе на экране «Сегодня» и в целях. |
| Сферы жизни, цвета, эмодзи и редактирование | Сохранены. Цвета задач и записей берутся из реальных сфер. |
| Смена языка, email, пароля, выход и удаление аккаунта | Сохранены в профиле. |
| Оценка дня и заметка | Доступны на экране «Сегодня»; в дневнике сворачиваются в отдельный раздел. |

## Намеренно изменённые элементы

- Семь пунктов и плавающая кнопка на телефоне заменены тремя выбранными вкладками, центральным добавлением и «Ещё». Остальные разделы доступны через «Ещё».
- Темы и цвета перенесены из профиля в «Оформление». Доступны «Спокойный фокус» и «Дневной ритм», акцент и фон, свой фон отдельно для светлой и тёмной темы.
- У задач убрана цветная полоса: сферу показывает чип. У дневника сохранена полоса на всю высоту карточки.
- Действия дневника перенесены в меню. Раскрытие доступно только для длинных записей.
- На компьютере используется боковая либо верхняя навигация и рабочая ширина содержимого.
- Блок «Главное на сегодня» не добавлялся по просьбе пользователя.

## Хранение настроек

Оформление и вкладки сохраняются на устройстве (`lifehub-appearance-v1`). Данные разделов продолжают храниться на сервере. Настройки оформления между устройствами пока не синхронизируются.

## Публикация

Workflow `Deploy` проверяет frontend и backend, собирает миграции, делает онлайн-копию SQLite и применяет миграции перед установкой новой версии. Новая таблица оценки дня входит в объединённые локальные коммиты; редизайн не удаляет пользовательские данные.
